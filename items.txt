# Eyes and brows
Close both eyes tightly // 両目をぎゅっと閉じる
Open both eyes as wide as you can // 目を思い切り見開く
Squint by raising the lower eyelids (as in bright light) // 下まぶたを上げて目を細める（まぶしいとき）
Raise both brows as high as you can (surprise) // 眉を思い切り上げる（驚き）
Pull the brows together and down (frown) // 眉を寄せて下げる（しかめ面）

# Mouth
Open the mouth vertically as far as you can // 口を縦に最大まで開く
With the mouth open, stretch the lips sideways // 口を開いたまま唇を横に引き伸ばす
With the mouth closed, pull the corners out and up // 口を閉じたまま口角を横上に引き上げる
With the mouth closed, pull the corners down // 口を閉じたまま口角を下に引き下げる
Pucker the lips and push them forward // 唇をすぼめて前に突き出す
Bite the teeth together and open the lips ("eee") // 歯を噛み合わせて唇を上下に開く（「いー」）
Close the mouth and puff out the cheeks // 口を閉じて頬を膨らませる
Stick the tongue out as far as you can // 舌を前に最大まで出す

# Expressions with directions or sides
sequence: Wink // ウィンク | Close the right eye only // 右目だけ閉じる | Close the left eye only // 左目だけ閉じる
sequence: Gaze (face forward) // 目線（顔は正面） | Up // 上 | Down // 下 | Right // 右 | Left // 左
sequence: Lips // 唇 | Press the lips together hard ("mmm") // 上下の唇をぎゅっと押し合わせる（「んー」とこらえる口） | Roll the lips into the mouth to hide them // 上下の唇を口の中へ巻き込んで隠す
sequence: Jaw (mouth slightly open) // 下顎（口を少し開けて） | Shift right // 右にずらす | Shift left // 左にずらす
sequence: Tongue out, point the tip // 舌を出して先を | Up // 上に向ける | Down // 下に向ける | Right // 右に向ける | Left // 左に向ける
